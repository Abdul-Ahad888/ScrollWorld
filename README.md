# ScrollWorld

ScrollWorld is an interactive, scroll-driven web experience that blends cinematic visuals, smooth animations, and immersive storytelling through motion-based UI. Built to create a premium user experience, the project transforms simple scrolling into a dynamic journey using modern front-end technologies.

🔗 **Live Demo:** https://scroll-world.netlify.app

---

## ✨ Features

- 🎬 Cinematic scroll-based storytelling
- ⚡ Smooth scrolling experience
- 🎞️ Advanced animations synced with user scroll
- 🌌 Interactive 3D visual elements
- 📱 Responsive modern UI design
- 🎨 Stylish icons and polished layouts

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES Modules)**
- **Vite** – Fast build tool & dev server
- **GSAP + ScrollTrigger** – Scroll animations & syncing
- **Lenis** – Smooth scrolling engine
- **Three.js** – 3D effects & immersive visuals
- **Bootstrap 5** – Layout & responsive styling
- **Font Awesome** – Icons
